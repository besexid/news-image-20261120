The World Today: one image that sums up the world's news of Friday 20 November 2026, drawn as a newspaper front page — the first-ever Trump–Xi–Putin summit in Shenzhen, the ICJ's genocide verdict on Myanmar, Cyclone Akvan's landfall in Odisha, a missile strike on Riyadh's tallest tower, COP31's fossil-fuel row on its final day, and Anthropic's record IPO amid a market selloff, plus a ticker of three more stories from the same day. Every story was reported on 20 November 2026 (see SOURCES.md). The picture is entry.png (1024 × 1024 PNG, drawn at build time by generate_image.py); the program, main.ts, copies it to the output directory byte for byte, every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
